# ClaudeMods

A small collection of reusable prompt mods for Claude.

## Available mods

- [Concise answers](mods/concise-answers/README.md) — keep responses focused and easy to scan.
- [Structured output](mods/structured-output/README.md) — organize responses with predictable headings and lists.

## Usage

Open a mod's `prompt.md` file and paste its contents into Claude's custom
instructions or at the start of a conversation. Mods are independent, so they
can be used individually or combined when their instructions do not conflict.

These prompts are intentionally simple and can be adapted to fit your
workflow.
